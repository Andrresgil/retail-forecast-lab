# Pronóstico semanal de ventas con Streamlit

Esta aplicación usa la regresión lineal entrenada en `ACA1.ipynb` para estimar las unidades vendidas de un producto en la semana siguiente. Recibe las ventas de las cuatro semanas anteriores.

**Fuente de datos:** Chen, D. (2015). *Online Retail*. UCI Machine Learning Repository. https://doi.org/10.24432/C5BW33. Licencia CC BY 4.0.
